> 原则：优先开源、优先跨平台、优先 Rust、Go 开发的。

- [VS Code](https://github.com/microsoft/vscode)
  - 人工 Review 代码，现在也就用个 Git
- [Zed](https://github.com/zed-industries/zed)
  - 基于 Rust，极速启动，用于临时编辑小文件
- [Antigravity](https://antigravity.google/)
  - 主力 Vibe Coding 工具，因为有一年的 Google One Pro
- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)
  - AI Review 代码，偶尔写写小工具

- [Logseq](https://github.com/logseq/logseq)
  - 主力双链笔记（Logseq DB 版本），用了一段时间的 Obsidian 又换回来了
- [Tine](https://github.com/martinkoutecky/tine)
  - 基于 Rust 的 Logseq OG 版本替代品（不用，观望中）

- [tty7](https://github.com/l0ng-ai/tty7)
  - Rust 编写的终端工作台，会话常驻，正在逐渐代替原生终端
- [Nushell](https://github.com/nushell/nushell)
  - 现代化 Shell，目前 Terminal 和 VS Code 中都用它
- [Oryxis](https://github.com/wilsonglasser/oryxis)
  - Rust 原生 SSH 客户端，替换了 FinalShell，用来连接我的 VPS
- [Yaak](https://github.com/mountain-loop/yaak)
  - 基于 Tauri 的 API 客户端，替换了 Apifox、Apipost、Postman

- [DBX](https://github.com/t8y2/dbx)
  - 基于 Tauri 的轻量数据库管理工具

- [Clash Verge](https://github.com/clash-verge-rev/clash-verge-rev)
  - 桌面代理客户端，Mihomo GUI
- [FlClash](https://github.com/chen08209/FlClash)
  - 基于 Flutter + Go (Mihomo) 的代理客户端，颜值高，手机上已经用它替换了 NekoBox

- [Snipaste](https://www.snipaste.com/)
  - 截图 + 贴图

- [Bitwarden](https://github.com/bitwarden)
  - 全平台主力密码管理工具

- [2FAS](https://github.com/twofas)
  - 2FAS Pass：密码管理工具
  - 2FAS Auth：双因素身份验证器

- [Ente](https://github.com/ente/ente)
  - Ente Auth：双因素身份验证器
  - Ente Photos：端到端加密相册
  - Ente Locker：私密文档管理

- [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor)
  - Windows 下最好的系统监控软件

- [Keyviz](https://github.com/mulaRahul/keyviz)
  - 鼠标键盘操作可视化工具，录屏的时候用

- [Cap](https://github.com/CapSoftware/Cap)
  - 基于 Rust 的录屏工具，替换掉 Kap

- [IINA](https://github.com/iina/iina)
  - macOS 下最好的现代视频播放器，基于 mpv

- [Mole](https://github.com/tw93/mole)
  - 极简高效的系统深度清理与卸载工具，有 CLI 和 GUI 两种模式，推荐 CLI

- [Ventoy](https://github.com/ventoy/Ventoy)
  - U 盘启动制作工具

- [Onin](https://github.com/Onin-app/Onin)
  - 自己开发的 uTools 替代品，目前只有我一个人用

- 坚果云
  - 国内最好的支持 WebDAV 的网盘

- [Muse](https://muse.ai/)
  - Meta 推出的个人 AI Agent，已经成了我的第二大脑

- 微信
  - 不得不用

- 𝕏
  - 当微博刷

- Telegram
  - 起飞的时候打开一下
